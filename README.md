# ספר המתכונים --- RecipesWebApp

אתר מתכונים סטטי בעברית, בתצוגת RTL. האתר מציג מתכונים, תמונות, מצרכים
והוראות הכנה. לאחר יצירת קובץ הנתונים, ניתן לפתוח את האתר ישירות בדפדפן
או לפרסם את תיקיית `public` באחסון סטטי כגון GitHub Pages.

## איך האתר עובד

-   `data.xlsx` הוא המקור לרשימת המתכונים והשיוך שלהם לקטגוריות,
    לתמונות, לקובצי המצרכים ולקובצי ההוראות.
-   `build.js` קורא את קובץ Excel ואת קובצי הטקסט, ומייצר את
    `public/recipes-data.js`.
-   תוכן המצרכים וההוראות משולב בתוך `recipes-data.js`. כך האתר אינו
    צריך לטעון קובצי טקסט בנפרד בזמן הריצה, דבר המאפשר לפתוח אותו גם
    באמצעות `file://`.
-   האתר עצמו נמצא בתיקיית `public`. הוא אינו זקוק לשרת או להתקנת חבילות
    Node.js כדי להציג מתכונים.
-   קוד האתר כולל ניסיון להשאיר את מסך הטלפון דולק באמצעות Screen Wake
    Lock בדפדפנים שתומכים בכך. התמיכה תלויה בדפדפן, במכשיר ובהרשאות/תנאי
    ההפעלה, ולכן אין הבטחה שהמסך יישאר דולק בכל מצב.

## מבנה התיקיות

``` text
RecipesWebApp/
├── data.xlsx                    # טבלת המתכונים
├── build.js                      # יצירת קובץ הנתונים לאתר
├── build.bat                     # הרצת build.js ב-Windows
├── lib/
│   └── xlsx-lite.js              # קוד עזר לקריאת קובץ Excel
├── Groceries/
│   ├── Groceries1.txt
│   └── Groceries_not_found.txt   # טקסט ברירת מחדל כשקובץ מצרכים חסר
├── Instructions/
│   ├── Instructions1.txt
│   └── Instructions_not_found.txt # טקסט ברירת מחדל כשקובץ הוראות חסר
└── public/
    ├── index.html                # דף האתר
    ├── script.js                 # התנהגות האתר
    ├── style.css                 # עיצוב האתר
    ├── recipes-data.js           # נוצר אוטומטית על ידי build.js
    └── Images/
        └── image_not_found.jpg   # תמונת ברירת מחדל
```

בתיקיות `Groceries` ו-`Instructions` קיימים גם קבצים נוספים. המבנה לעיל
מציג את הקבצים המרכזיים בלבד.

## דרישות

-   **להצגת האתר:** אין צורך ב-Node.js או בשרת. פותחים את
    `public/index.html` בדפדפן.
-   **לעדכון הנתונים:** נדרש Node.js מותקן במחשב, כדי להריץ את
    `build.bat` או את `build.js`.
-   **לפרסום ב-GitHub Pages:** יש להעלות את קובצי האתר שנוצרו מתוך
    `public` למאגר ולכוון את GitHub Pages לתיקייה/מקור הפרסום המתאים.
    קובץ `recipes-data.js` חייב להיכלל בפרסום לצד `index.html`,
    `script.js` ו-`style.css`, ותיקיית `Images` צריכה להישאר לצד קובצי
    האתר.

## הוספת מתכון או עדכון מתכון

1.  פותחים את `data.xlsx`.

2.  מוסיפים שורה או עורכים את שורת המתכון. לפי הקוד הנוכחי, העמודות
    נקראות לפי הסדר הבא:

      עמודה   תוכן
      ------- -----------------------------------------
      A       קטגוריה
      B       שם המתכון
      C       שם התמונה, ללא הסיומת `.jpg`
      D       שם קובץ המצרכים, ללא הסיומת `.txt`
      E       שם קובץ הוראות ההכנה, ללא הסיומת `.txt`

3.  שומרים את קובץ Excel.

4.  מוסיפים או מעדכנים את הקבצים המתאימים:

    -   תמונות: `public/Images/`
    -   מצרכים: `Groceries/`
    -   הוראות הכנה: `Instructions/`

5.  יש לוודא ששמות הקבצים תואמים לערכים שב-Excel. אין להוסיף את הסיומות
    לעמודות C--E, משום שהקוד מוסיף אותן בעצמו.

6.  לוחצים פעמיים על `build.bat`.

7.  לאחר הודעת הצלחה, פותחים מחדש את `public/index.html` או מרעננים את
    האתר שפורסם. אם הדפדפן מציג נתונים ישנים, מבצעים רענון חזק
    (`Ctrl+Shift+R`).

**חשוב:** כל שינוי ב-`data.xlsx`, בקובצי המצרכים או בקובצי ההוראות מחייב
הרצה מחדש של `build.bat`. הקובץ `public/recipes-data.js` נוצר אוטומטית,
ואין לערוך אותו ידנית --- העריכה תידרס בבנייה הבאה.

## כללי קבצים וברירות מחדל

-   שמות התמונות צריכים להתאים לשמות שב-Excel, עם סיומת `.jpg`, והן
    נשמרות בתוך `public/Images`.
-   אם התמונה חסרה, האתר משתמש ב-`public/Images/image_not_found.jpg`.
-   אם קובץ מצרכים חסר, הבנייה משתמשת
    ב-`Groceries/Groceries_not_found.txt`.
-   אם קובץ הוראות חסר, הבנייה משתמשת
    ב-`Instructions/Instructions_not_found.txt`.
-   שורה בקובץ מצרכים או הוראות שמסתיימת בנקודתיים (`:`) מוצגת ככותרת.
    שורות ריקות אינן מוצגות.
-   שמות הקבצים והנתיבים חייבים להתאים בדיוק, כולל אותיות גדולות/קטנות
    וסימני פיסוק, במיוחד בפרסום ב-GitHub Pages.

## שימוש באתר

-   האתר נפתח עם חלון בחירת מתכון.
-   ניתן לבחור קטגוריה או להציג את כל המתכונים, ואז לבחור מתכון.
-   כפתורי הקודם/הבא נעים בהיסטוריית המתכונים שנבחרו במהלך השימוש.
-   האתר מוצג בעברית ובכיווניות מימין לשמאל.

## פתרון תקלות

### האתר לא מציג את המתכונים

1.  ודאו שקיים `public/recipes-data.js`.
2.  הריצו שוב את `build.bat`.
3.  בדקו שהבנייה הסתיימה בהצלחה ושאין הודעת שגיאה.
4.  רעננו את הדפדפן.

### מוצגת תמונת ברירת המחדל

בדקו ששם התמונה בעמודה C תואם לשם הקובץ שבתיקייה `public/Images`, ללא
`.jpg` בעמודה.

### המצרכים או ההוראות אינם נכונים

בדקו את שמות הקבצים בעמודות D ו-E ואת התוכן בתיקיות `Groceries`
ו-`Instructions`, ואז הריצו שוב את `build.bat`.

### האתר עובד מקומית אך לא לאחר פרסום

ודאו שכל קובצי האתר נמצאים במקור הפרסום יחד, שהנתיבים יחסיים ונכונים,
ושקובץ `recipes-data.js` ותיקיית `Images` הועלו גם הם. ב-GitHub, שמות
קבצים ונתיבים חייבים להתאים בדיוק.

## קבצים שאין לערוך ידנית

-   `public/recipes-data.js` --- קובץ נתונים שנוצר על ידי `build.js`.
