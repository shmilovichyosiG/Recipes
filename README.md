# אתר המתכונים

**גרסה סטטית, בלי שרת בכלל.** לחיצה כפולה על `public/index.html` פותחת את
האתר בדפדפן, בלי להריץ שום דבר.

## מבנה התיקיות

```
RecipesWebApp/
├── data.xlsx           ← טבלת המתכונים
├── Images/               ← תמונות jpg (image_not_found.jpg = ברירת מחדל)
├── Groceries/             ← קבצי טקסט של מצרכים
├── Instructions/           ← קבצי טקסט של הוראות הכנה
├── build.js                ← בונה מחדש את public/recipes-data.js מתוך data.xlsx + הקבצים
├── build.bat                ← הפעלת build.js בלחיצה כפולה (Windows)
├── lib/xlsx-lite.js
└── public/
    ├── index.html            ← זה מה שפותחים בדפדפן
    ├── style.css
    ├── script.js
    └── recipes-data.js         ← נוצר אוטומטית - אל תערוך ידנית
```

## איך מוסיפים/מעדכנים מתכון

1. פתח את `data.xlsx` והוסף/ערוך שורה: קטגוריה | שם | שם תמונה (בלי `.jpg`) | שם קובץ מצרכים (בלי `.txt`) | שם קובץ הוראות (בלי `.txt`)
2. שים את קבצי התמונה/מצרכים/הוראות בתיקיות המתאימות, עם השמות שרשמת.
3. שמור את `data.xlsx`.
4. **לחץ פעמיים על `build.bat`** — זה בונה מחדש את `public/recipes-data.js`.
5. רענן את `index.html` בדפדפן (Ctrl+Shift+R).

בלי שלב 4, שינויים ב-`data.xlsx` **לא** יופיעו באתר.

## דרישה טכנית יחידה

צריך **Node.js** מותקן, אבל **רק כדי להריץ את `build.bat`** — לא כדי להציג את האתר.
אפשר להעתיק את כל התיקייה (כולל `Images`/`Groceries`/`Instructions`) לכל מחשב אחר
והיא תעבוד שם בלי שום התקנה נוספת.

## אם תרצה בעתיד לחזור לגרסת השרת

`server.js` ו-`run.bat` עדיין בפרויקט ועובדים בדיוק כמו קודם (קריאה חיה מ-`data.xlsx`
בלי שלב בנייה) — `node server.js` ואז `http://localhost:3000`.
